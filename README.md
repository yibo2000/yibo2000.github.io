# yibohe.github.io

Personal academic homepage of Yibo He, built with [Hugo](https://gohugo.io/) and [HugoBlox](https://hugoblox.com/), deployed via GitHub Pages.

- Live site: https://yibohe.github.io/
- Content lives in `content/`; edit Markdown files and push to `main` — the site rebuilds and deploys automatically via GitHub Actions.
- Local preview: `hugo server`
